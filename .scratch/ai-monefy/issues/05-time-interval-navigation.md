# 05: Time Interval Navigation & Period Filtering

**What to build:** A time period navigation header supporting Day, Week, Month, Year, All, and Custom intervals with period stepping arrows (< and >).

**Blocked by:** 03: Circular Donut Wheel & Balance Hub

**Status:** done

- [x] Clicking interval tabs (Day, Week, Month, Year, All) changes the active period filter and updates the header date label.
- [x] Clicking < or > steps backward or forward by the active period (e.g., previous month or next month).
- [x] The donut chart, center balance, and transaction queries dynamically re-aggregate to reflect only transactions within the selected timeframe.
