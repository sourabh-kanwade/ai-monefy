# 10: Data Export / Import & Global Currency Settings

**What to build:** Export and import capabilities for CSV and JSON backups, and a global currency selector affecting monetary formatting.

**Blocked by:** 03: Circular Donut Wheel & Balance Hub

**Status:** ready-for-agent

- [ ] User can trigger a CSV export that downloads all transactions formatted with date, type, category, account, amount, and note.
- [ ] User can create and download a complete JSON database backup.
- [ ] User can upload a previously exported JSON backup file to restore accounts, categories, and transactions.
- [ ] Changing the preferred currency symbol (USD, EUR, GBP, INR, JPY, etc.) immediately re-formats all monetary values across the application.
