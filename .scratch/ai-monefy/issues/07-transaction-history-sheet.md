# 07: Transaction History Sheet & Real-Time Search

**What to build:** A collapsible bottom transaction sheet grouping records by date, with instant text search, detail viewing, editing, and deletion.

**Blocked by:** 03: Circular Donut Wheel & Balance Hub

**Status:** done

- [x] Transactions are listed grouped by date in reverse-chronological order with category icons, amounts, accounts, and notes.
- [x] Typing into the search bar filters transactions in real time across notes and category names.
- [x] Tapping a transaction opens an edit view allowing the user to modify the amount, category, account, note, or date.
- [x] Deleting a transaction removes it from storage and immediately updates the wheel chart and balances.
