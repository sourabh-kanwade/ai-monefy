# 02: Monefy Calculator Keypad

**What to build:** A modal or dedicated numeric keypad providing Monefy-style transaction entry with inline arithmetic evaluation (+, -, *, /), category selection, account selection, optional notes, and custom transaction dates.

**Blocked by:** 01: Walking Skeleton (Local Expense Entry & Storage)

**Status:** ready-for-agent

- [ ] Tapping numeric keys 0-9 and decimal point enters digits into the expression display.
- [ ] Entering arithmetic operations (such as `15 + 4.50`) evaluates and displays the calculated subtotal before saving.
- [ ] User can pick an account, customize the transaction date, and attach a text note before confirming.
- [ ] Confirming the keypad saves the calculated amount to the selected category and closes the modal.
